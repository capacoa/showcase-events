# Showcase Events Structured Data Generator

This is a repository to generate and publish structured data about showcasing events (aka contact events) and their showcasing artists.

### Google Sheet Structured Data Generator
The initial minimal viable product (MVP) was designed as a Google Sheet form, using a google script (.gs) generated by Claude AI.

A free-edit version of this tool can be accessed in this Google Directory:
